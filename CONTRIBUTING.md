# Contributing

This list is only as good as the questions and experiences people add to it. Contributions welcome:

1. **Adding a question:** put it in the right category, one question per line. No need for a "correct answer" — this is a question bank, not an answer key.
2. **Adding a real interview experience:** add an entry to [Real Interview Experiences](README.md#real-interview-experiences) with the company name (or "Anonymous"), role, and a short writeup of the questions/format. Don't share anything covered by an NDA.
3. **Adding a prep resource:** must be genuinely useful for SRE/incident-response interview prep, not general career advice.
4. One addition per pull request, with a short note on where it's from.
5. Keep it civil — no naming individual interviewers negatively, no venting about a company. Critique the process, not people.
